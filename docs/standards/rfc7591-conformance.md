# RFC 7591 Conformance Matrix

| Requirement | Status | Implementation |
|---|---|---|
| JSON registration request | Implemented | `DynamicClientRegistrationClient` |
| Client metadata processing | Implemented | `ClientMetadata` |
| Redirect URI validation | Implemented | `ClientMetadata` |
| Default grant and response types | Implemented | `effective_grant_types`, `effective_response_types` |
| `jwks_uri` and inline `jwks` | Implemented | `ClientMetadata` |
| Mutual exclusion of `jwks_uri` / `jwks` | Implemented | model validation |
| Software statements | Implemented through port | `SoftwareStatementProcessor` |
| Initial access token | Implemented through policy | `InitialAccessTokenRegistrationPolicy` |
| Open registration | Implemented | `OpenRegistrationPolicy` |
| Client identifier issuance | Implemented | `ClientIdentifierGenerator` |
| Client secret issuance | Supported by response/record model; not generated by Phase 1 profile | product adapter |
| Registration error JSON model | Implemented | `RegistrationErrorResponse` |
| Extension metadata | Implemented | Pydantic extra metadata + policy validation |
| Registration management | Implemented separately by RFC 7592 module | `oauth/rfc7592` |
