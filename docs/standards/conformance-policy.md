# Conformance Policy

A module cannot claim RFC support until its conformance document identifies:

- implemented normative MUST requirements;
- implemented SHOULD requirements;
- intentionally deferred SHOULD requirements with rationale;
- unsupported optional features;
- deployment restrictions;
- source files implementing each requirement;
- positive and negative tests proving each requirement.

Marketing labels such as “complete RFC support” are prohibited unless every normative path in the declared profile is covered.
