# Source Material

Primary normative sources are the RFC Editor, official A2A specification, official MCP specification, W3C specifications, and SPIFFE specifications.

The supplied A2A security PDFs are treated as architectural input, not normative replacements for the standards. They identify the trust triangle and candidate standards, including RFC 7591/7523 for onboarding, RFC 8707 for target binding, RFC 9449 for sender-constrained invocation, RFC 8705 and SPIFFE for enterprise identity, and DID/VC, RAR, and GNAP for later phases.

Implementation documents must cite exact RFC sections rather than relying only on summaries.
