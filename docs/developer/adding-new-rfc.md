# Adding a New RFC

1. Confirm the standard is final enough for implementation.
2. Add a category-appropriate package and package README.
3. Define public models, policies, ports, services, errors, and adapters.
4. Map normative requirements in a conformance document.
5. Add positive, negative, adversarial, and integration tests.
6. Compose through a facade only when the module is independently complete.
7. Update standards mapping, roadmap, changelog, and release notes.
